# pehlione.io - GitHub Pages

This branch contains the static site files for [pehlione.com](https://pehlione.com/). The application source code, setup instructions, and development documentation are on the [main branch](https://github.com/mustafa-oezdemir/pehlione.io/tree/main).

The website is built from main by the GitHub Actions deployment workflow. This README is for repository visitors; it is not part of the website UI.
